# 网申助手

基于UniApp的求职应用，包含投递记录、简历管理、日历安排等功能。

## 功能特性

- ✅ 一键登录
- 📋 投递记录管理
- 📄 简历管理
- 📅 日历热力图显示安排
- 🎨 现代化深色主题设计

## 技术栈

- UniApp - 跨平台移动应用框架
- SCSS - 样式预处理器

## 页面结构

- `/pages/login/login` - 登录页
- `/pages/index/index` - 首页
- `/pages/records/records` - 投递记录页
- `/pages/resume/resume` - 简历管理页
- `/pages/calendar/calendar` - 日历页

## 按钮样式

所有按钮采用设计稿风格：
- 深色背景
- 彩色渐变边框
- 彩色发光效果
- 圆角设计
